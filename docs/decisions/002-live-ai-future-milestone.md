# Live AI is a future milestone

Current v2 release is guided exploration: fixed, reviewed answers with deterministic topic routing in the visitor's browser. Preserve the visible `Curated answers · no live AI` label. No live Worker or inference backend is part of this release gate.

Live generative AI requires a separately scoped milestone with an isolated JAGAU knowledge base and Worker, exact origin allowlist, mandatory rate/cost controls, bounded input/history/output/time, safe canonical evidence references, confidentiality/injection/unsupported-claim tests and real endpoint verification. It must remain visually distinguishable from guided content. Do not enable or advertise it while completing this blocked guided-mode release.
