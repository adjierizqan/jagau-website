# DEFINE → DESIGN → PLAN

Owner: Adjie. Classification: public company identity / Client Product. Version: 2.0.
Audience: prospective collaborators and reviewers seeking credible software engineering evidence.
Problem: a company site needs its own identity and a direct path from questions to real work.
Success: a visitor can identify JAGAU, explore a reviewed engineering topic, inspect its source case study and contact the founder; all essential content survives disabled JavaScript.

MUST: independent static Next.js site, original editorial identity, integrated guided question explorer, three attributed founder case studies, semantic navigation, responsive design, metadata, contact, deterministic quality gates, evidence and rollback instructions.
SHOULD: separately deployed real AI only with available credentials, enforced cost limits and real negative/live tests.
LATER: CMS, accounts, blog, translations, heavy 3D and custom forms.

Acceptance frozen before implementation: all essential navigation and three work summaries visible without JS; four starter questions and typed supported questions reveal reviewed answers and canonical evidence links; unsupported claims and healthcare requests return explicit uncertainty; no response masquerades as AI; keyboard focus, reduced motion, no overflow at 375/768/1024/1440; unit, lint, typecheck, production export, static links/assets and Chromium/WebKit browser checks pass. Release only after DNS/hosting inventory and external HTTPS/email checks. No changes to portfolio, healthcare systems or email records.

Design: warm paper (#f3f0e7), ink (#202820), brick (#a33d26). Serif editorial proposition contrasts with compact engineering labels. Work fragments, document rules and numbered routes provide domain identity. No external fonts or decorative illustrations. System Georgia and Helvetica/Arial avoid network/font dependencies; wordmark uses tight uppercase rhythm and an original bracket-like terminal.

References: existing founder portfolio for prompt → answer → evidence and provenance only; do not copy its desktop shell, personal identity or UI. Awwwards typography collection (https://www.awwwards.com/websites/art/) for type hierarchy only; no individual entry's assets, layout or motion copied. Next.js static export docs (https://nextjs.org/docs/app/guides/static-exports) for prerendered HTML architecture.

Build order: reviewed company data → server-rendered pages → guided client explorer → quality gates → screenshot review → versioned release artifact → deployment only when access gates are met.

AI decision: unavailable Cloudflare capabilities in this session; complete honest guided mode as permitted by brief scope guard #3. Do not ship an untested Worker or inference integration. The portfolio's streaming/error/history/CORS mechanism is inspected as reference, not imported wholesale. Future live output must be validated against canonical references before presentation; prompt instructions alone are insufficient.
